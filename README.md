### 🧠 About

I build and scale a **HIPAA- and SOC 2-compliant AI healthcare platform** at **ElkTech**, automating
document intelligence, admission qualification and ICD coding for skilled nursing facilities.

My work spans the full stack: multi-agent orchestration with **LangGraph**, **FastAPI** backends,
cloud-native architecture on **GCP**, and the guardrails that make LLMs safe to run in a regulated
environment. I care about AI systems that are not just clever, but reliable, secure and genuinely
useful in production.
